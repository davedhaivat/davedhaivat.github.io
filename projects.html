Machine Vision & Automation

Cognex Corporation Fixtureless Configuration Application

Firmware managementSAP integrationMulti-location deployment

A custom web application built to eliminate the scalability bottlenecks of legacy fixture tables used for firmware updates across Cognex's global distribution centers. The app enables operators to scan a product barcode, fetch firmware files via SAP integration, auto-discover matching devices on the network, and push firmware updates — with real-time notifications and error logging.

~6 moDevelopment
USA & IntlLocation
SAPIntegrated

Outcomes

Fixture-table bottleneck eliminatedBarcode → SAP → network → device pipeline deliveredDeployed across USA & international sites

Key contributions

Mapped the end-to-end application flow — from barcode scan and SAP API call to network device discovery and firmware push — translating a technically complex process into clear documentation and wireframes.

Conducted customer-facing sessions to capture pain points of the existing fixture table process and defined requirements for the new fixtureless approach across multiple distribution center environments.

Created EPICs and user stories in JIRA with detailed acceptance criteria covering key flows — device matching, firmware update, success/failure notifications, and error logging.

Collaborated with the customer's technical team to investigate and resolve a critical firmware log generation defect requiring deep hardware communication analysis.
